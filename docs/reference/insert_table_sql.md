# insert_table_sql

Insert a table into the database

## Usage

``` r
insert_table_sql(conn, db_table_name, table, check_db_table = TRUE)
```

## Arguments

- conn:

  An established database connection

- db_table_name:

  Name of a table in the database

- table:

  A table in the database

- check_db_table:

  whether to check database table. Default = TRUE.
