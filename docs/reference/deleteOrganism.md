# deleteOrganism

Remove organisms from database

## Usage

``` r
deleteOrganism(conn_handler, organism, verbose = TRUE)
```

## Arguments

- conn_handler:

  An R object obtained from SigRepo::newConnhandler() (required)

- organism:

  A list of organisms to be removed (required)

- verbose:

  Logical; whether to print diagnostic messages. Defaults to 'TRUE'.
